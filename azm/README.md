# عَزم

تطبيق ويب شخصي (RTL، Mobile-first، PWA) لكسر التسويف وبناء الصلابة الذهنية.
Next.js 16 (App Router) + TypeScript + Tailwind CSS v4. البيانات محلية في جهازك (localStorage)، والتذكيرات عبر تقويم الجوال، بدون سيرفر.

## التشغيل محليًا

```bash
cd azm
npm install
npm run dev        # http://localhost:3000
```

- للاختبار السريع: أضف `?fast=1` للرابط (مثل `/stuck?fast=1` أو `/timer?fast=1`) وكل دقيقة تصير ثانية.
- الـ service worker (الشغل بدون إنترنت) يشتغل في نسخة الإنتاج بس:

```bash
npm run build && npm start   # http://localhost:3000
```

## النشر على Vercel

1. ادخل [vercel.com](https://vercel.com) بحساب GitHub.
2. **Add New → Project** ← اختر الريبو `ifaghd`.
3. في **Root Directory** اختر `azm` (مهم، لأن الريبو فيه مشاريع ثانية).
4. اترك الباقي على الافتراضي (Framework: Next.js) واضغط **Deploy**.
5. بعد دقيقة يطلع لك رابط مثل `https://azm-xxx.vercel.app`. هذا رابطك الثابت.

> صدّر ملف التقويم **من الرابط النهائي** (مو من localhost)، عشان روابط التذكيرات تفتح الموقع الصحيح.

## تثبيته على الجوال

- **آيفون:** افتح الرابط في Safari ← زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط في Chrome ← ⋮ ← «تثبيت التطبيق».

بعد أول فتح، يشتغل بدون إنترنت. الضغط المطوّل على الأيقونة (أندرويد) يعطيك اختصارات: «أنا عالق الحين»، «سجّل تأجيل»، «المؤقت».

## التذكيرات عبر التقويم

من **المزيد ← الإعدادات والتقويم**: اختر الأحداث، وعدّل أوقاتها، ثم:

**آيفون**
1. اضغط «أضف لتقويم الآيفون».
2. تطلع قائمة الأحداث ← «إضافة الكل» ← اختر التقويم.
3. (بديل) «حمّل ملف ‎.ics» ← تطبيق الملفات ← التنزيلات ← اضغط على azm.ics ← «إضافة الكل».

**Google Calendar**
1. حدث وحدة: زر «+ Google» جنب الحدث ← حفظ.
2. كل الأحداث: حمّل ‎.ics ← من الكمبيوتر افتح calendar.google.com ← ⚙️ الإعدادات ← «استيراد وتصدير» ← اختر الملف ← استيراد.

كل حدث له UID ثابت: لو عدّلت وقت وصدّرت مرة ثانية، الحدث يتحدّث بدل ما يتكرر. الخطة الموقوفة تنصدّر كـ«ملغاة»، والمحذوفة احذف حدثها يدويًا.

## الهيكل

```
src/
  app/                 الصفحات (كل مجلد = صفحة) + calendar.ics/route.ts + manifest.ts
  components/
    stuck/             خطوات «أنا عالق الحين»
    today/             بطاقات الصفحة الرئيسية
    plans/             خطط إذا–فإن والمسارات
    timer/             بومودورو ونافذة مونستر
    log/               سجل التسويف والتحليل
    program/ habits/ review/ control/ tasks/ constitution/ settings/
    ui/                أزرار، حقول، أيقونات
  lib/
    storage/           طبقة التخزين (adapter) — بدّلها هنا فقط
    db.ts              المستودعات: الدوال الوحيدة اللي تقرأ وتكتب البيانات
    stats.ts           حسابات التحليل والعادات (دوال صافية)
    timer.ts           بدء/إنهاء/إيقاف المؤقت
    ics.ts             مولّد iCalendar (RFC 5545)
    calendar.ts        تحويل الإعدادات والخطط لأحداث تقويم
    content/           الاقتباسات، برنامج الـ30 يوم، المشاعر، النصائح، محفزات الصلاة
public/
  sw.js                Service worker (بدون إنترنت)
  icons/               أيقونات التطبيق
```

## النسخ الاحتياطي

البيانات في متصفح الجهاز بس. من الإعدادات: **تصدير** ينزّل ملف JSON، و**استيراد** يرجّعه (حتى على جهاز ثاني).

## التبديل لـ Supabase لاحقًا

اكتب كلاس جديد يطبّق `StorageAdapter` (read / write / remove) فوق جدول واحد:

```sql
create table azm_kv (key text primary key, value jsonb not null, updated_at timestamptz default now());
```

ثم غيّر سطر واحد في `src/lib/storage/index.ts`. المكونات ما تحتاج أي تعديل.
