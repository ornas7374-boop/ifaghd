# التقرير الأسبوعي لـ SEO

يُسحب من Google Search Console عبر Supermetrics (المصدر `GW`، الحساب `https://kashtat.vercel.app/`).
نفس الاستعلامات كل أسبوع، والمقارنة دائمًا مع الأسبوع السابق.

## المؤشرات

| المؤشر | الاستعلام | الهدف |
|---|---|---|
| الفهرسة | تقرير `SITEMAPS`: الحقول `path, submitted, indexed, errors, warnings` | المفهرس = المرسل، وصفر أخطاء |
| الظهور والضغطات | `Date, impressions, clicks, ctr, position` آخر 7 أيام مقارنة بالسابقة | نمو أسبوعي |
| الكلمات | `query, impressions, clicks, ctr, position` آخر 28 يوم | الكلمات المستهدفة في `seo-keywords.md` تظهر |
| الصفحات | `page, impressions, clicks, ctr, position` آخر 28 يوم | كل صفحات المدن والأنواع لها ظهور |

## قواعد قراءة النتائج

| الحالة | الإجراء |
|---|---|
| كلمة ترتيبها بين 8 و20 | أقرب فرصة: قوّ الصفحة المستهدفة (نص، روابط داخلية، عنوان) |
| صفحة ظهورها عالي والنقر أقل من 2% | أعد كتابة العنوان والوصف |
| صفحة مرسلة غير مفهرسة | افحصها بأداة «فحص عنوان URL» واطلب الفهرسة |
| كلمة جديدة غير موجودة في الخريطة | أضفها إلى `seo-keywords.md` وحدد صفحتها |

## ملاحظات
- أول بيانات تظهر بعد أيام إلى أسبوعين من إرسال خريطة الموقع.
- الموسم: البحث يرتفع من نوفمبر ويبلغ ذروته في ديسمبر (Google Trends)، فالمقارنة الأدق سنويًا.
- صفحات الأنواع والأدلة نصها ثابت: راجعها كلما تغيرت الأماكن (المدن، الأسعار، الحجز بالساعة).
