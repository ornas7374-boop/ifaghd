شارة حالة الطلب في لوحة المالك وصفحة الزبون، دائمًا أيقونة وكلمة معًا.

- Classes: `k-badge` + `k-badge--new`, `k-badge--deposit`, `k-badge--confirmed`, `k-badge--declined`, `k-badge--expired`.
- المسار: `new` ← `deposit` ← `confirmed`، أو `declined`، أو `expired` إذا ما رد المالك خلال 12 ساعة.
- `confirmed` تعني أن المالك ضغط «استلمت العربون»، وعندها فقط يظهر الموقع الدقيق.
- لا تعتمد على اللون: الأخضر والأحمر لا يُفرّقان وحدهما، والكلمة والأيقونة هما الفرق.
