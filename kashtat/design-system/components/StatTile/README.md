بطاقة رقم في لوحة المالك: طلبات جديدة، دخل الشهر، نسبة الإشغال.

- Classes: `k-stat`, `k-stat__value`, `k-stat__label`, `k-stat__delta` (+ `--up` / `--down`), `k-stat__icon`.
- المستهلك يوفر الرقم والوحدة والتسمية والتغير. التغير يحمل إشارة ▲ أو ▼ ونصًا، لا لونًا فقط.
- العدّاد يصعد من 0 خلال `duration-hero` بـ `easing-out`، مرة واحدة عند الظهور، ويتوقف مع prefers-reduced-motion.
