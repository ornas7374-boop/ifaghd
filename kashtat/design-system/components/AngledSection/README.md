شريحة عريضة بحافة مائلة بلون `band` أو `band-alt`، لصفحات الهبوط: الهيرو، شرح الزبون، شرح المالك.

- Classes: `k-slant`, `k-slant--alt`, `k-slant__inner`, `k-rule`, `k-disc`.
- ركّب الشرائح فوق بعض بالتناوب: `k-slant` ثم `k-slant--alt`. الأولى تبدأ مستقيمة من الأعلى.
- ميل الحافة من المتغير `--slant` (الافتراضي 56px)؛ لا تغيّره داخل الصفحة الواحدة.
- النص `on-band` والثانوي `on-band-muted`. الصورة الدائرية `k-disc` 200px، تطفو ببطء بـ `k-drift`، وتكبر قليلًا عند hover.
- المستهلك يوفر العنوان، فقرة قصيرة، زر واحد، وصورة دائرية (تُقص من صورة حقيقية).
