زر كبسولة للإجراء الرئيسي في كل شاشة: إرسال طلب الحجز، قبول، تسجيل مخيم.

- Class: `k-btn` + one of `k-btn--primary`, `k-btn--accent`, `k-btn--ghost`, `k-btn--on-band`; size `k-btn--sm`.
- زر `primary` واحد فقط في كل منطقة. استعمل `accent` لإجراء المالك «استلمت العربون» فقط.
- `k-btn--on-band` فقط فوق `band` أو `band-alt`.
- الزر يرتفع 2px عند hover ويضغط عند active. سهم `k-btn__arrow` يتحرك لليسار (اتجاه RTL). لا تضف حركة ثانية.
- المستهلك يوفر النص (فعل قصير) وأيقونة السهم اختيارية. الزر المعطّل `disabled` يشرح السبب في النص المجاور.
