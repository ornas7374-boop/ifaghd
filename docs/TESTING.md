# الاختبار

## التشغيل

```bash
# قاعدة بيانات اختبار منفصلة
createdb ifaghd_test --owner ifaghd

# إن كانت قاعدتك تحتاج كلمة مرور، ضعها في ملف محلي (مستثنى من Git):
echo 'TEST_DATABASE_URL=postgresql://ifaghd:PASSWORD@localhost:5432/ifaghd_test' > .env.test.local

npm test                 # كل الاختبارات (١٤٧)
npm run typecheck        # فحص الأنواع
npm run smoke            # ٨ سيناريوهات محادثة كاملة على قاعدة بيانات حقيقية
```

الاختبارات تستخدم `ifaghd_test` (أو `TEST_DATABASE_URL` من `.env.test.local`)، تُرحّل تلقائياً،
وتُفرّغ الجداول بين كل اختبار. لا تلمس قاعدة التطوير.

`LLM_PROVIDER=mock` يُضبط داخل الاختبارات. المزوّد الوهمي **بديل اختبار للنموذج فقط** —
كل ما عداه (SQL، الأدوات، الحواجز، التصعيد، الحفظ) هو كود الإنتاج نفسه.

## اختبارات أمنية بارزة

هذه هي التي تهم فعلاً عند بيع النظام:

```
✓ لا يمكن الوصول لطلب عميل آخر حتى لو ذُكر رقمه صراحة
✓ get_customer لا تملك معامل يطلب عميلاً آخر
✓ محاولة كشف البرومبت تُرفض بدون تسريب وبدون إزعاج موظف
✓ الوكيل لا يملك صلاحية order:write ولا customer:write إطلاقاً
✓ الأسرار (مفاتيح API، روابط قاعدة البيانات) تُحذف من أي رد
✓ رقم عميل آخر يُحذف، ورقم التتبع لا يُحذف
✓ قاعدة معرفة مستأجر لا تظهر لمستأجر آخر
✓ رقم طلب فيه محارف SQL يُرفض قبل الوصول لقاعدة البيانات
✓ فلتر تسريب البرومبت يُختبر ضد البرومبت الحقيقي المبني (يفشل عند أي انحراف)
```

## اختبارات منع الاختلاق

```
✓ سعر لم يأتِ من أداة → يُحجب الرد ويُصعّد
✓ ادعاء "تم إلغاء الطلب" → يُحجب
✓ ادعاء "تم استرجاع المبلغ" → يُحجب
✓ رقم طلب مخترع → يُحجب
✓ وعد توصيل غير مستند → يُحجب
✓ سعر جاء من أداة فعلاً → يمرّ
✓ أرقام عربية (٢٥ ريال) من قاعدة المعرفة → تمرّ
✓ سؤال خارج النطاق → قاعدة المعرفة تُرجع صفر نتائج
```

## اختبارات المرونة

```
✓ فشل الـLLM → تصعيد لموظف، لا صمت
✓ فشل الإرسال → الرد يُحفظ ليراه الموظف
✓ فشل التلخيص → المحادثة تستمر
✓ رسالة مكرّرة من Meta → تُتجاهل، لا رد مزدوج
✓ رسالة صوتية → تُعالج بلا انهيار
✓ محادثة يتولاها موظف → الوكيل يصمت
```

## اختبار الدخان (Smoke)

```bash
npm run smoke
```

يشغّل ٨ محادثات كاملة عبر خط المعالجة الحقيقي وقاعدة البيانات الحقيقية،
ويطبع رد الوكيل لكل حالة. قابل لإعادة التشغيل: يعيد ضبط حالة المحادثات
للعملاء التجريبيين قبل البدء.

يشمل: استعلام طلب، سؤال سياسة، طلب موظف، عميل غاضب، محاولة كشف برومبت،
محاولة وصول لبيانات عميل آخر، طلب غير موجود، سؤال خارج النطاق.

## الاختبار اليدوي مع نموذج حقيقي

المزوّد الوهمي يثبت أن **الأنابيب** تعمل. جودة الصياغة تحتاج نموذجاً حقيقياً:

```bash
LLM_PROVIDER=anthropic ANTHROPIC_API_KEY=sk-ant-... npm run smoke
```

راجع الردود يدوياً: هل اللهجة طبيعية؟ قصيرة؟ بلا إيموجي زائد؟
هل استخدم بيانات الأداة فعلاً بدل التعميم؟

```sql
SELECT step, status, duration_ms, detail->>'summary'
```
