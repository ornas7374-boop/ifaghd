# آداب عامة — Motion Graphics Plan

مشروع HyperFrames يطبّق أسلوب الموشن جرافيك في الفيديو المرجعي (ريلز Social Heaven، أحمر/أسود/أبيض) على مقطع «آداب عامة».

## 1. تحليل الأسلوب المرجعي

| العنصر | ما في المرجع | كيف طُبّق هنا |

| الألوان | أسود عميق، أحمر صارخ (#E5141B تقريباً)، أبيض | نفس الثلاثي: لوحات سوداء، كلمة مفتاحية حمراء، لوحات حمراء معكوسة للكلمات القوية |

| حركة النص | كلمة-كلمة، دخول من blur مع صعود بسيط، الكلمة الحمراء "تنط" بـ overshoot | stagger 0.11s، blur 10px→0، y 22→0، الكلمة الحمراء scale 1.45→1 (back.out) |
| الخطوط الزخرفية | أقواس بيضاء رفيعة تُرسم عبر الكادر | قوس يُرسم (stroke draw 1.1s) مع بداية كل لقطة |

| الكاميرا | push-in بطيء مستمر على العنصر | push/pull بطيء 5% داخل كل لقطة |
| بطاقات المعلومة | لوحة داكنة بشبكة grid خفيفة | بطاقة الحديث: شبكة خفيفة، شريط أحمر، كشف عبارة-عبارة |

| المزامنة | كل كلمة تظهر لحظة نطقها | التوقيت مأخوذ من ظهور الكلمات المفتاحية الأصلية (المتزامنة مع الكلام) |

## الإصدار 2: حركة مستمرة + مؤثرات صوتية

المرجع يتحرك فيه شيء كل ~0.5–1.5 ثانية، فأُضيف نظام حركة "محيطي" يملأ الفترات الهادئة:

| العنصر | التوقيت | الوصف |
|---|---|---|
| نبضات الكاميرا | 2.35، 5.25، 10.05، 12.15، 13.9، 17.75، 21.55، 22.7، 25.4، 27.25، 28.1، 30.6، 35.6، 39.65، 43.3، 45.55، 49.2، 51.45، 54.4 | زووم 4.5% + إزاحة ±9px على مقاطع التشديد في الكلام (مستخرجة من طاقة الصوت) |
| شارة السلسلة «# آداب عامة» | طول الفيديو، تلمع عند 0.7، 12.8، 28.6، 44، 52.6 | تغطي الهاشتاق الأصلي وتعيد بناءه |
| أقواس التركيز | 8.55، 14.9، 22.75، 51.5 | زوايا بيضاء/حمراء حول المتحدث |
| حلقات مدارية | 9.0–15.8، 28.2–29.85، 52.0–53.4 | دائرة بيضاء تُرسم + حلقة حمراء منقّطة تدور |
| لمعات ضوء | 11.1، 19.0، 29.0، 52.6 | شريط ضوئي مائل يعبر الكادر |
| أقواس إضافية | 9.6، 14.35، 23.0، 40.2 | |

**المؤثرات الصوتية** (69 مؤثر، مكتبة Pixabay المجانية، تحت الصوت الأصلي):
- whoosh: دخول كل لوحة (0.16) والقطعات (0.30)
- pop: الكلمة الحمراء (0.26)، كلمات الحديث المميزة، الشارة
- click-soft: نبضات الكاميرا (0.42)، click: أقواس التركيز
- sparkle: اللمعات (0.10)، impact-bass: بطاقة الختام (0.12)

## ملاحظات تقنية

- الفيديو الأصلي فيه نصوص محروقة (burned-in). كل لوحة جديدة موضوعة **فوق** النص الأصلي بالضبط (إحداثيات المصدر × 1.5) ومقفولة معه داخل طبقة الكاميرا، فما يظهر أي تكرار.
- الصوت الأصلي محفوظ كما هو، وتسلسل المشاهد بدون تغيير.
- الدقة: 1296×864 (المصدر 866×576 مكبّر 1.5× عشان النصوص تطلع حادة)، 30fps.

## التعديل والإنتاج

```bash
cd work/adab-motion
npx hyperframes preview          # معاينة وتعديل في Studio
npx hyperframes check            # فحص
npx hyperframes render -q delivery -o renders/adab-motion.mp4
```

- لتغيير نص أو توقيت: عدّل `data-start` / `data-duration` أو نص `<span>` داخل `index.html`.
- الألوان في `:root` (`--red`, `--plate`).
- ملفات الفيديو (`assets/video/source.mp4`) والمخرجات (`renders/`) غير مرفوعة للمستودع لأنه عام؛ ضع المقطع الأصلي في `assets/video/source.mp4` (أعد ترميزه بـ `-g 30`) قبل الرندر.
