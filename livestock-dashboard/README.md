# قسم الإنتاج الحيواني — محطة الأبحاث والتجارب

Dashboard احترافي بالعربية (RTL بالكامل) لإدخال بيانات الإنتاج الحيواني السنوية ومتابعتها ومقارنتها، مع قاعدة بيانات حقيقية — لا بيانات وهمية ولا تخزين داخل الواجهة.

هذا مشروع Next.js **مستقل تمامًا** عن بقية هذا المستودع (لا علاقة له بصفحة الهدية في الجذر) وله قاعدة بياناته وتبعياته الخاصة.

## الستاك

- **Next.js 16** (App Router + TypeScript)
- **SQLite** (`better-sqlite3`) — قاعدة بيانات حقيقية بملف واحد، بدون إعداد خارجي
- **Tailwind CSS v4** — تصميم RTL كامل، Responsive، ويدعم الوضع الليلي
- **Recharts** — الرسوم البيانية التفاعلية
- **Zod** — التحقق من صحة المدخلات

## البنية

```
src/
  app/            الصفحات (الرئيسية، إدخال البيانات، البيانات، التقارير) + API routes
  components/     مكوّنات واجهة مشتركة (بطاقات، جداول، رسوم بيانية، إشعارات...)
  lib/            قاعدة البيانات، الاستعلامات، التحقق من الصحة، الألوان، التنسيق
data/             ملف قاعدة البيانات (يُنشأ تلقائيًا عند أول تشغيل، غير مرفوع لـ Git)
```

## قاعدة البيانات

جدولان فقط:

- `animal_types` — أنواع الحيوانات (مزروعة مبدئيًا بأربعة أنواع: الأبقار، الأغنام، الإبل، الخيل)، ويمكن إضافة أنواع جديدة من صفحة "إدخال البيانات" مباشرة دون أي تعديل بالكود.
- `production_records` — سجل واحد لكل (سنة × نوع حيوان) يحوي المواليد والنفوق وكمية الأعلاف، مع قيد `UNIQUE(year, animal_type_id)` يمنع التكرار.

السنة حقل رقمي حر (وليست قائمة ثابتة بالكود) — أي سنة مستقبلية (2027 وما بعدها) تعمل فورًا بمجرد إدخال بيانات لها، بدون أي تعديل على الكود أو قاعدة البيانات.

## كيف تشغّله محليًا

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. قاعدة البيانات تُنشأ تلقائيًا في `data/livestock.db` عند أول طلب، وجميع القيم تبدأ فارغة كما هو مطلوب — لا أرقام تجريبية.

## متغيرات البيئة

| المتغير | إلزامي | الوصف |
|---|---|---|
| `DB_PATH` | لا | مسار ملف قاعدة البيانات. افتراضي: `./data/livestock.db` |

## النشر

يحتاج هذا التطبيق **قرص دائم (persistent disk)** لأن قاعدة بياناته ملف SQLite على القرص (نفس ملاحظة صفحة الهدية في جذر هذا المستودع) — استضافه على Railway أو Render مع Volume مثبّت، وعيّن `DB_PATH` على مسار داخل ذلك الـ Volume.

## التصدير (Excel / PDF)

زر التصدير في صفحة التقارير موجود كواجهة جاهزة (معطّل حاليًا) — إضافة التصدير الفعلي لاحقًا لا يحتاج تعديل بنية الصفحات، فقط ربط الزر بمكتبة توليد الملفات.
