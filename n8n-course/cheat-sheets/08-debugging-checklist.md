# 🐛 Debugging Checklist

## المنهجية السبعية

```
1. صِف العَرَض بدقة   ← ليس "لا يعمل"
2. حدد الموقع          ← أي عقدة، أي تنفيذ
3. افحص المدخل         ← ⭐ لا تفترض — انظر
4. حدد التوقع          ← ما الذي تتوقعه العقدة؟
5. اعزل الفجوة         ← ⭐ هذا هو السبب
6. أصلح                ← سريع + جذري
7. امنع التكرار        ← تحقق · اختبار · مراقبة
```

## قبل أي شيء

```
[ ] هل الـ workflow مفعّل (Active)؟
[ ] هل ظهر التنفيذ في Executions أصلًا؟
[ ] هل أستخدم Production URL لا Test؟
[ ] هل حفظتُ آخر تعديل؟
[ ] كم item دخل العقدة الفاشلة؟
```

## جدول التشخيص السريع

| العَرَض | الأسباب المرجّحة |
|---|---|
| لم تعمل العقدة إطلاقًا | 0 items · غير مفعّل |
| عملت مرة والمتوقع عدة | item فيه مصفوفة → Split Out |
| عملت عدة والمتوقع مرة | عدة items → Aggregate / Execute Once |
| `undefined` | مسار خاطئ · **مخرج AI في `output`** |
| `Cannot read property of undefined` | حقل مفقود → `?.` |
| الشرط يفشل وهو صحيح | ⭐ **نوع البيانات** (نص/رقم) |
| بيانات اختفت بعد IF | **فرع غير موصول** |
| بيانات اختفت بعد Set | `Include Other Input Fields` مطفأ |
| بيانات مغلوطة بعد Merge | وضع `by position` خاطئ |
| رسائل مكررة | رد بطيء + بلا idempotency |
| `fetch is not defined` | **Code Node بلا شبكة** |
| الحلقة عالجت دفعة واحدة | **الرجوع غير موصول** |
| `401` | هوية: مفتاح/توكن منتهٍ |
| `403` | **صلاحيات** لا هوية |
| `429` | حد المعدل → **تباطؤ لا retry** |
| `5xx` | خطأ عندهم → أعد المحاولة |
| بطء مفاجئ | فهارس · N+1 · تراكم بيانات |
| لا شيء يحدث | Active · Test URL · منطقة زمنية |
| بوت يخلط المستخدمين | **Session ID غير مضبوط** |

## الأدوات

| الأداة | متى |
|---|---|
| **Executions** | ابدأ منها دائمًا |
| **Input/Output** | ما دخل وما خرج |
| `console.log()` | طباعة قيمة عند الشك |
| **Pin Data** | عزل المتغيرات |
| **curl** | اختبار API خارج n8n |

## تجزئة التعبيرات

```
{{ $json.data.users[0].profile.email }} لا يعمل؟

{{ $json }}                    ← ماذا يوجد؟
{{ $json.data }}               ← موجود؟
{{ $json.data.users }}         ← مصفوفة؟
{{ $json.data.users[0] }}      ← فيها عنصر؟
...حتى أول undefined ← هناك المشكلة
```

## متى تسأل AI؟

```
❌ عند أول خطأ
✅ بعد الخطوات 1–5، بسؤال دقيق:
   "العقدة X استقبلت {...} وأتوقع Y لكنها أخرجت Z. لماذا؟"
```
