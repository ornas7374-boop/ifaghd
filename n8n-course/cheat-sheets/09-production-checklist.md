# 🚀 Production Checklist

## الموثوقية
```
[ ] كل استدعاء خارجي له معالجة فشل
[ ] Retry على الأخطاء العابرة فقط (لا 401/404)
[ ] Error Workflow مرتبط
[ ] Timeouts محددة
[ ] العمليات idempotent
[ ] Dead Letter Queue للفشل النهائي
```

## البيانات
```
[ ] تحقق من كل مدخل خارجي
[ ] التعامل مع null والحقول المفقودة
[ ] أنواع البيانات مضبوطة صراحةً
[ ] حماية من التكرار (منطق + قيد قاعدة)
[ ] المعرّفات مطبَّعة (بريد lowercase · هاتف موحّد)
```

## الأداء
```
[ ] لا حلقات بلا داع
[ ] Rate Limits محترمة
[ ] Pagination مفعّلة
[ ] استعلامات مفهرسة
[ ] التصفية عند المصدر لا بعد الجلب
[ ] حذف تلقائي لبيانات التنفيذات القديمة
```

## المراقبة
```
[ ] تنبيه عند الفشل
[ ] Heartbeat يكشف الصمت ⭐
[ ] سجلات كافية للتشخيص
[ ] مؤشرات النجاح مُتابَعة
```

## الأمان
```
[ ] لا أسرار في العقد
[ ] webhooks مؤمَّنة
[ ] استعلامات معاملية
[ ] أقل صلاحية ممكنة
[ ] لا أسرار في السجلات
[ ] الترخيص متوافق مع نموذج العمل
```

## الصيانة
```
[ ] أسماء واضحة لكل عقدة (فعل + مفعول)
[ ] وصف للـ workflow (غرض · مدخل · مخرج · تبعيات · مالك)
[ ] Sticky Notes عند القرارات غير البديهية
[ ] لا منطق مكرر
[ ] لا قيم مثبَّتة يجب أن تكون إعدادات
[ ] Pin Data منزوع ⚠️
```

```

```

## النشر
```
[ ] بيئة إنتاج منفصلة عن التطوير
[ ] N8N_ENCRYPTION_KEY محفوظ خارجيًا ⚠️
[ ] Postgres لا SQLite
[ ] HTTPS مفعّل
[ ] نسخ احتياطية **مُختبَرة الاستعادة**
[ ] خطة تراجع واضحة
```

## التسليم للعميل
```
[ ] دليل تشغيل مكتوب
[ ] كيفية التعديلات الشائعة
[ ] جهة الاتصال عند المشاكل
[ ] العميل يعرف كيف يتحقق من الحالة
[ ] اتفاق الصيانة واضح
[ ] النطاق وما هو خارجه موثَّقان
```
