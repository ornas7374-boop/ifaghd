## ⚠️ المخرج مغلَّف في `output`

```json

```
✅ `{{ $json.output.category }}`
❌ `{{ $json.category }}`  ← سبب `undefined` الأشهر

## اختيار الأداة

| الحاجة | الأداة |
|---|---|
| قرار بقاعدة واضحة | **IF / Switch** ← لا AI |
| تصنيف لفئات معروفة | **Text Classifier** |
| استخراج حقول من نص | **Information Extractor** |
| توليد نص | استدعاء LLM بسيط |
| خطوات متعددة غير معروفة مسبقًا | **AI Agent** |

⚠️ **وكيل لمهمة تصنيف = 10× التكلفة ودقة أقل**

## هيكل الأمر الإنتاجي

```
1. الدور        أنت مساعد...
2. المهمة       صنّف/استخرج...
3. الخيارات     A | B | C | OTHER
4. القواعد      اختر واحدة · لا تخترع · OTHER عند الغموض
5. أمثلة        "..." → A
6. صيغة المخرج  (Structured Output Parser)
```

## RAG

```
فهرسة:   مستندات → تقسيم → embeddings → قاعدة متجهية
استعلام: سؤال → متجه → بحث تشابه → مقاطع → نموذج → إجابة
```

| الوضع | الاستخدام |
|---|---|
| `insert` | الفهرسة |
| `load` | بحث لمرة واحدة (**وللتشخيص**) |
| `retrieve-as-tool` | ✅ RAG المعياري |

| الممارسة | القيمة |
|---|---|
| حجم المقطع | 300–800 كلمة |
| التداخل | 10–15% |
| بيانات وصفية | المصدر والقسم |

🐛 **إجابات سيئة؟ افحص الاسترجاع أولًا بوضع `load` — 90% من المشاكل هناك، لا في النموذج**
